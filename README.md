## ✅ Setup Checklist

Follow these steps to finalize your GitHub profile:

### Phase 1: Banner SVGs
- [ ] Generate animated banner using the master prompt (1–2 hours)
- [ ] Export `banner-dark.svg` and `banner-light.svg` to `/assets` folder
- [ ] Verify banner renders correctly in both dark and light modes

### Phase 2: Stats Cards (Self-Hosted)
- [ ] Create GitHub Personal Access Token (PAT)
  - Settings → Developer settings → Tokens (classic) → Generate new
  - Scope: `repo`
  - ⚠️ Copy immediately, never share publicly
- [ ] Fork [`anuraghazra/github-readme-stats`](https://github.com/anuraghazra/github-readme-stats)
- [ ] Deploy to Vercel
  - Sign up with GitHub (Hobby plan, free)
  - Add New Project → Import fork
  - Add environment variable: `PAT_1 = your_token`
  - Deploy
- [ ] Replace `YOUR_VERCEL_INSTANCE` in README with your Vercel deployment URL

### Phase 3: Contribution Snake
- [ ] Create `.github/workflows/snake.yml` (template provided in repo wiki)
- [ ] Enable repository Actions permissions
  - Settings → Actions → General → Workflow permissions
  - Select: "Read and write permissions"
  - ⚠️ This is **repository settings**, not account settings
- [ ] First workflow run (12-hour cron): wait for green ✅ before adding snake to README

### Phase 4: Social Badges & README
- [ ] Update email, LinkedIn, and portfolio URLs in badge section
- [ ] Push all changes to `main` branch
- [ ] Verify README renders correctly on your GitHub profile
